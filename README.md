## ⚡ Overview

AI Battle Arena brings multiple AI models into one competitive environment.

Instead of asking one AI for an answer, challenge different models with the same prompt and compare their responses side by side.

From reasoning and accuracy to creativity and response quality, explore how different AI models approach the same problem.

**One challenge. Multiple minds. One arena.**

## ✨ Key Features

| Feature | Description |
|---|---|
| ⚔️ AI Model Battles | Compare responses from multiple AI models. |
| 🤖 Multiple LLMs | Integrations with different AI providers. |
| 🧠 LangChain Integration | Manage model interactions through LangChain. |
| 📊 Response Comparison | Evaluate answers based on quality, accuracy and creativity. |
| ⚡ Interactive Experience | Submit challenges and explore model responses. |
| 🔌 API Integration | Connect with different LLM providers. |

## 🥊 How It Works

**01 — Choose Your Opponents**

Select the AI models you want to compete against.

**02 — Submit a Challenge**

Give all selected models the same prompt or question.

**03 — Watch the Battle**

Each model processes the challenge and generates its response.

**04 — Compare the Results**

Explore the different answers and decide which model performed better.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Nisarg1223/Ai-Battle-Arena.git
```

### 2. Navigate to the project

```bash
cd Ai-Battle-Arena
```

### 3. Install dependencies

Install the frontend and backend dependencies separately:

```bash
cd Backend
npm install
```

```bash
cd ../Frontend
npm install
```

### 4. Configure environment variables

Configure the required API credentials and database connection strings in the environment files.

You will need the credentials for the AI providers and MongoDB used by your project.

**Important:** Never commit API keys or secret credentials to GitHub.

### 5. Run the application

Check the `scripts` section in each `package.json` and run the appropriate development command for the frontend and backend in separate terminals.
